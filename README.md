# Keyora

Modern local password manager built with Python and PySide6.

## Features

- Master password authentication
- AES encrypted vault
- Password generator
- Dynamic categories
- Search system
- Dark mode UI
- Clipboard auto-clear

## Technologies

- Python
- PySide6
- SQLite
- cryptography
- argon2-cffi

## Security

- Passwords are encrypted locally
- Master password is hashed using Argon2
- No cloud storage
- No plaintext password storage
